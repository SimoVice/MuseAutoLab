# Three-minute demo script

Prepared 2026-10-30. Proposed English narration for the completed captioned demo.
This is an editing script, not an additional performance or hardware claim. Use actual
captures from one recorded project throughout the main journey. Keep the selected
project's final revision and package together. The spoken text can be recorded by the
presenter; the captioned cut remains understandable without audio.

## On-screen evidence labels

- Throughout product footage: **Recorded app session · waits shortened** if any wait is cut.
- If a separate saved-result capture is used: **Recorded Meta result · reopened locally · no new inference**. Label any substituted-response capture **Offline response replay**.
- First sourced view: **Original Jubilee CAD · CC BY 4.0 · custom layout proposed with Meta**.
- Cold bay: **Temperature target · cooling unvalidated**.
- Arm sweep: **Kinematic concept**.
- Export: **Actual project files · revision [observed revision]** and the observed generation time.
- Close: **Working digital prototype · hardware validation pending**.

Use a small number of readable close-ups: the requirement, accepted change, arm and opened
guide. Do not imply that a source model is arbitrary CAD invented by Meta, an animation is
physics, a virtual camera is a photo-analysis result, or a replay is fresh inference.
The impossible-width line is included only when the recorded negative case is present.

## Recording and delivery notes

The video's quantitative captions must come from its selected project and measured run.
Do not copy stock volumes, bed deltas, package counts or export timings from another
rehearsal. If evidence from a separate recorded project is needed, label that switch
explicitly instead of presenting false project continuity. Keep original captures,
an edit manifest, caption timings and the final media validation locally.

Public links, hosted playback and final submission status belong in the completed reviewer
entry only after those destinations actually exist and have been checked. The submission
draft is separate from this script; neither file certifies event registration or eligibility.
