Science Jubilee: Python protocols for a commissioned Jubilee

Use Science Jubilee as the upstream programming route for a compatible Jubilee build. Its Python interfaces describe the machine, tools, decks and labware; it provides example notebooks. First configure and commission the actual controller, tool and labware interfaces. MuseAutoLab has not integrated or tested a Science Jubilee hardware-control adapter for this design. Provisional controller entries are not evidence of a compatible commissioned controller.

Create another pipetting protocol

  1. Save this hardware project. Describe the next pipetting task, liquids, source and destination labware, transfer amounts, repeats and constraints in chat.
  2. Compare the task with the accepted platform, pipette, tip rack and labware. Keep compatible hardware; request a design revision for any changed fit or interface.
  3. Use the declarative template below as a specification. Assign real source positions, mixing, tip policy and liquid handling parameters explicitly; no values are inferred here.
  4. Download protocol-template.json and protocol-preview.py together. Run python protocol-preview.py protocol-template.json locally to check the recorded bindings and volume arithmetic and print the logical schedule. This does not connect to hardware.
